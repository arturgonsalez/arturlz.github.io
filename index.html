(03) About

I help product teams ship work that holds up under real use, not just in screenshots.

Approach

I work close to engineering. I prototype in code when it helps, write decisions down so the team can argue with them, and treat the design system as a daily tool rather than a quarterly deliverable. I prefer fewer features done well to more features half done.
